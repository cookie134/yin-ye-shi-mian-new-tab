# 因夜失眠标签页

一个供 Edge 使用的新标签页扩展。主页以每日壁纸、居中的时钟和搜索为主，收藏与页面便签从底部操作，左上角收纳默认折叠。

## 本地加载

1. 在 Edge 打开 edge://extensions/，开启开发人员模式。
2. 选择“加载解压缩的扩展”，目录选择 D:\标签页。
3. 修改代码后，在扩展页面点击“重新加载”，再打开新标签页。

## 使用

- 点击时间打开设置；点击时间上方的搜索引擎名称切换引擎或添加包含 {query} 的 HTTPS 搜索模板。
- 底部“+”添加收藏。长按收藏图标后可拖动排序，拖入回收站删除；网页、链接的右键菜单可以直接收藏；支持标签栏右键扩展入口的 Edge 版本也会显示同名菜单。点击扩展工具栏图标可收藏当前网页，作为标签栏菜单不可用时的入口。
- 底部便签按钮新建页面便签。便签可拖动、缩放、编辑局部文字格式，设置每日提醒或定时删除，并可放进左上角的收纳箱。
- 左上角收纳默认关闭，展开后可新建和命名收纳箱，收纳或贴出便签。
- 左上角收纳的整条标题都是展开/折叠按钮；若想完全隐藏，可点击时间进入设置，关闭“显示左上角便签收纳”，也可以直接告诉斯塔显示或隐藏。
- 左上角收纳改为收起时的轻量胶囊、展开时的浅色列表；便签颜色以侧边细线保留，减少大面积色块。
- 底部 ✦ 打开斯塔（Star）的中央对话工作台；新标签页默认不展开。左侧可搜索、切换和新建对话；当前对话的重命名与删除在右上角菜单中，删除需再次确认。聊天消息可编辑或删除，便签不会随聊天记录一同删除。AI 创建的便签会以结果卡片展示，可直接定位到页面便签或左上角收纳箱。窄屏下会话列表可折叠。
- 搜索栏下方轮换显示少量有出处的固定摘句和冷知识。配置 API 后，后台会预生成并保存 10 条来自随机来源的新短句；首次填满前继续显示固定短句，填满后每次打开新标签页会立即取出一条，后台再补充一条。每次补充会调用所选 AI 服务。鼠标双击短句、触屏轻触或键盘按回车会打开斯塔的新对话，她会先问你是否对这句感兴趣；摘句和冷知识在对话中提供出处链接。未接入 API 时，她会说明只能先帮你记便签。近期事项另起一行。到时提醒与打开新标签页时的近期行程提示会以浏览器/系统通知出现，在其他网页也能看到。聊天输入在未接入 API 时可保存为页面便签；接入后，助手能按请求创建便签，判断单次或每日提醒，并为有明确截止时间的事项设置定时删除；未指定删除时间的单次提醒按设置中选择的立即、1 小时、5 小时或 24 小时自动清理；删除便签也会取消它关联的单次提醒。配置 API 后，便签文字和时间信息会发送到所选服务以生成行程提示。
- 设置中的“提醒通知”可检查 Edge 通知权限、已注册闹钟数，并发送即时及约 1 分钟后的定时测试通知；若通知权限已允许但系统没有弹窗，也需检查 Windows 免打扰与 Edge 的通知设置。设置还可修改背景、导入导出配置。旧版设置页的便签草稿会自动转成页面便签。
- 斯塔的对话设定以友善、知性和克制为主。AI 创建提醒、或用户在已接入 API 时设置每日提醒，可预先准备贴合事项的一句简短提示；通知会先讲清待办事项，用户修改便签正文后会丢弃旧文案。未接入 API 的便签仍按原文提醒；提醒触发时不会额外调用模型。
- 从首页短句打开的对话会保留短句来源；斯塔知道原创短句是自己为首页写的，也能区分所选摘句与冷知识的出处。聊天输入按回车发送（未接入 API 时保存便签），Shift+回车换行；中文输入法选字时不会触发发送。旧版短句对话会自动识别原有开场白并补上来源上下文。
- 斯塔会在同一会话内携带更长的聊天历史，包括较早提到的身份、称呼与计划；不同会话互不混用。请求内容过长时，会优先保留开场与最近消息，并限制发送长度以控制 API 开销。完整聊天记录仍保存在本地，用户可自行编辑或删除。
- AI 服务可选 DeepSeek、OpenAI（ChatGPT）、Google Gemini、Groq、OpenRouter，以及自定义 OpenAI 兼容接口。切换服务会自动填入默认接口地址，并为各服务分别保存 Key；输入 Key 后从服务的 `/models` 接口实时读取模型列表，支持搜索和刷新。读取失败时可选预设或自定义模型 ID。导出配置会清除所有服务的 Key，导入时保留本机各服务已有的 Key。
- 收藏优先读取网站的 favicon.ico，失败时退回浏览器 favicon 或字母标识；长按拖动可排序，停留在另一收藏上创建文件夹。打开文件夹后，每条网址旁可点“移出”，单独回到收藏栏；右键文件夹可重命名、打开全部或释放网址。
- 页面外观支持必应每日壁纸、纯背景颜色、单张 HTTPS 图片和本地/网络图库。可以导入整个本地图片文件夹或多张图片；GIF、WebP 和 APNG 保持原有动画。图库可按顺序或随机轮播，设置轮播间隔，并分别选择自动轮播、滚轮切图的淡入淡出、平移、缩放或无动画。滚轮只在主页切图，不占用设置、聊天、便签等区域的滚动。
- 页面外观还可调整时钟、日期、搜索引擎名称、搜索栏与短句的文字颜色，以及无描边、柔和描边或清晰描边。斯塔也可以通过对话修改这两项；看不清文字时，优先加强描边，不猜测她看不到的背景明暗。
- 接入 API 后，可以直接让斯塔修改页面外观、轮播与随机选图、搜索引擎、收藏及其文件夹、便签与收纳箱、提醒相关设置；斯塔返回结构化操作，页面校验后自动执行，并在对话里报告结果。聊天输入区的“＋ 图片”支持上传本地背景，图片留在本机扩展图库，只把文件名和临时编号交给 AI；通过对话选中的图片组成当前播放列表，图库里的其他图片仍保留。API Key 使用聊天区“连接 API”或设置中的密码输入框在本机保存，不作为对话内容发送给 AI。
- 本地图片以快照方式存在扩展的 IndexedDB 中，不持续读取原文件夹。每次最多导入 200 张、合计 400 MB，单张不超过 25 MB。JSON 配置导出不包含图片文件，跨设备导入后需要重新导入本地图库；同一浏览器导入配置不会删掉原有本地图片。

## 开发检查

在项目目录运行 `npm install`，然后用 `npm run check` 做严格类型检查、`npm run build` 更新 `dist`，并用 `npm run test:reminders`、`npm run test:home`、`npm run test:background`、`npm run test:provider` 检查提醒、首页、背景收藏和 AI 服务设置。
