## 功能

### 安静的主页

- 简洁的时钟、日期与搜索栏。
- 独立的斯塔入口，支持 **Alt + S** 快速打开。
- 默认无操作 **30 秒**后淡出所有组件，只显示背景。
- 按任意键或移动鼠标即可唤醒。
- 等待时间可以自定义，也可以关闭纯背景模式。
- 支持窄屏布局与系统减少动态效果设置。

### 自由选择背景

- 支持网络图片 URL、本地图片与文件夹导入。
- 支持 GIF、WebP、APNG 等动画图片。
- 支持单张展示、顺序轮播与随机轮播。
- 可设置轮播间隔，选择是否通过滚轮切图。
- 自动轮播与滚轮切图可分别设置动画效果。
- 本地图片以快照形式保存，导入后不依赖原文件夹。

### 收藏与文件夹

- 添加网站收藏，显示网站图标。
- 长按拖动排序，拖入回收站删除。
- 将收藏停留在另一收藏上，可组合成文件夹。
- 支持文件夹重命名、批量打开与单独移出网址。
- 删除文件夹时，成员网址会回到收藏栏。
- 支持网页或链接右键收藏，也可点击扩展工具栏图标收藏当前网页。

> 浏览器标签栏右键菜单的支持情况取决于 Edge 版本；未显示入口时，可使用网页右键菜单或工具栏按钮。

### 便签与提醒

- 便签支持拖动、缩放、颜色与文字格式调整。
- 使用多个收纳箱整理便签。
- 支持单次提醒、每日提醒与定时删除。
- 单次提醒后的保留时间可在设置中调整。
- 通过浏览器／系统通知提醒，无需停留在新标签页。
- 提供通知测试与提醒自检入口。

### 多会话聊天

- 中央工作台采用会话列表与聊天区域的双栏布局。
- 支持新建、搜索、命名与删除会话。
- 聊天消息可以编辑或删除。
- **Enter** 发送，**Shift + Enter** 换行。
- AI 创建便签后显示结果卡片，可直接查看对应便签。
- 保留同一会话的历史上下文；实际记忆范围仍受模型上下文长度限制。

### 有出处的短句

首页展示摘句与有趣的知识，并附来源。

未配置 API 时，使用内置精选内容；配置后，后台读取真实来源并生成新内容，维护一个 **10 条新句队列**。首次队列准备完成前显示固定短句，就绪后每次打开取出一条，并在后台补充。

双击短句，可以打开斯塔继续讨论。

## AI 服务

支持以下服务：

- DeepSeek
- OpenAI
- Google Gemini
- Groq
- OpenRouter
- 自定义 OpenAI 兼容接口

选择服务后自动填入对应接口地址，连接后可获取模型列表。不同服务的 API Key 分别保存。

**项目不提供 API Key。** 模型调用费用、可用模型与服务限制，以对应平台为准。

## 安装

目前通过本地加载方式使用：

1. 下载仓库并解压。
2. 确认目录中包含 `manifest.json` 和 `dist/`。
3. 打开 `edge://extensions/`。
4. 开启「开发人员模式」。
5. 点击「加载解压缩的扩展」，选择项目根目录。
6. 打开新标签页。

如果下载的源码不包含编译产物，请先按下面的开发步骤构建。

## 使用限制

- 提醒依赖浏览器运行及系统通知权限；电脑休眠或浏览器完全退出时，不保证准时弹出。
- AI 可能理解错误，重要提醒请检查结果卡片中的时间与内容。
- 来源与证据校验可以降低短句误引风险，但不能保证生成内容完全准确。
- 多个新标签页同时修改数据时，暂不支持完整的冲突合并。
- 自动化检查不能替代真实设备上的通知、动画与交互验证。
